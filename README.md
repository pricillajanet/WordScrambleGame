Word Scramble Game

A simple desktop word puzzle game developed using Java Swing. Players need to unscramble randomly shuffled letters to find the correct word.

Features

- Randomly scrambled words
- Answer validation (case-insensitive)
- Score system (+10 points for each correct answer)
- Hint feature for each word
- Timer to track completion time
- Final score and time display
- Restart button to play again
- Empty input validation

Technologies Used

- Java
- Java Swing
- Java AWT

How to Play

1. Run the application.
2. A scrambled word will appear on the screen.
3. Enter the correct word in the text field.
4. Click **Check Answer** to submit.
5. Click **Hint** if you need a clue.
6. Earn 10 points for each correct answer.
7. Complete all words to finish the game.
8. Click **Restart** to play again.
